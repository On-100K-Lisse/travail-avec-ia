## Points de vigilance

**Moteur pre-1.0 (11)** — `AILevel` y fait planter le chargement. Ecrire les probabilites en
valeur directe, ou activer sur le drapeau d'IA du personnage :

Master Hand, Bowser, Emerl, Neo Metal Sonic, Bowser Jr, Koopa, Dark Pit,
Metal Knuckles (omega), Mighty, Jet the Hawk, Wave

**IA ecrite a la main (10)** — aucune IA d'auteur a l'origine, comportement entierement issu
du patch, a observer en match :

Donkey Kong (MvC), Koopa, Dark Link Mythos, Dark Pit, Rayman, Altair, Puss in Boots,
Solid Snake (Chibi), Solid Snake (STG), Wave

**Attaque reduite chez les Mythos** — Ganondorf 89, Cloud 89, Dark Link 82, Mario/Luigi/Zelda 75.
Ce n'est pas une erreur : leur auteur (Shiruzato) les a construits sur une base de 100 differente,
et leur attaque s'applique a une echelle **relative**. Leur mettre la valeur brute du tier
doublerait leurs degats.
