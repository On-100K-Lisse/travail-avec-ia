# ai/kai/dlss5

Branche de **Kai** — recherche et expérimentation autour du DLSS 5 et d'openNR.

## Contenu

- `docs/DLSS5_310.9.16_RTX4070.md` — compilation d'une DLL DLSS compat-fp16
  (openNR, NVIDIA 310.9.16) à partir des sources, validation par hachage
  (identique à la référence) et mesures de performance en jeu sur RTX 4070.

Présentation du dépôt et des autres projets : voir le README de la branche `main`.
