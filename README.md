# ai/kai/veille-osint

Branche de **Kai** — documentation d'outils de veille automatisée sur des sources
publiques (OSINT).

## Contenu

- `docs/ARCHITECTURE.md` — l'agent de veille jeux vidéo : collecte de sources
  publiques, analyse par l'API Gemini, alertes courriel immédiates pour les
  cibles prioritaires et récapitulatif hebdomadaire.

Présentation du dépôt et des autres projets : voir le README de la branche `main`.
