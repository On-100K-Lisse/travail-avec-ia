# ai/kai/soutien-it

Branche de **Kai** — documentation de soutien informatique : méthodes de
diagnostic, modèles de documents et organisation d'une base de connaissances.
Née du DEP en soutien informatique et de l'atelier de réparation de l'école.

## Contenu

- `docs/FICHE_INTERVENTION.md` — le modèle de fiche d'intervention de l'atelier :
  un format Markdown rapide à remplir sur place, et la spécification d'une liste
  Microsoft Lists « Fiches d'intervention » pour accumuler les cas traités.
- `docs/KIT_DEPANNAGE.md` — la méthode de dépannage de l'atelier : sauvegarde
  d'abord, une variable à la fois, documenter pendant l'intervention.

Présentation du dépôt et des autres projets : voir le README de la branche `main`.
