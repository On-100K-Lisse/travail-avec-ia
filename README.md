# Unreal Engine 5 — espace de travail ChatGPT

Branche `ai/chatgpt/ue5` du dépôt `travail-avec-ia`.

Cette branche est réservée aux prototypes, recherches, guides et outils de développement Unreal Engine 5 réalisés avec ChatGPT. Aucun prototype spécifique n'y est encore publié.

## Organisation

- Les documents MUGEN restent uniquement dans `ai/chatgpt/mugen`.
- Les travaux DLSS 5 vont dans `ai/chatgpt/dlss5`.
- Les mods de jeux vont dans `ai/chatgpt/mods`.
- Les règles communes et la liste des branches se trouvent dans le README de `main`.
