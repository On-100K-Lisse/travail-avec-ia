# ai/kai/homelab

Branche de **Kai** — documentation du homelab d'On-100-K-Lisse : un laboratoire
personnel pour apprendre l'administration système et réseau, et héberger ses
propres services.

## Contenu

- `docs/PLAN_RELANCE_HOMELAB.md` — le plan complet de relance du serveur Dell
  sous Debian 13 : remise en route, validation du SSH, accès distant via
  Tailscale, bloqueur de publicités DNS (AdGuard Home) et surveillance.

**État du projet : en pause.** Le plan est le point de départ officiel le jour de
la relance — chaque phase a son point de contrôle avant de passer à la suivante.

Présentation du dépôt et des autres projets : voir le README de la branche `main`.
